## 🚀 Features

### 4 Accessibility Personas
- ♿ **Wheelchair Profile** - Slope < 4.8° · Step-Free Guaranteed
- 👁️ **Blind · 3D Spatial** - HRTF Binaural Chimes + Haptics  
- 🤟 **Deaf · ISL Visual** - Indian Sign Language + Strobe
- 🧠 **Low Sensory Noise** - Acoustic Load < 65 dB Calm Corridors

### Wildest-Dreams Differentiators
- 🚨 **Fire / Emergency SOS Mode** - Lock lifts & route to Refuge Zone
- 📅 **Pre-Arrival Auto Room-Swap** - Exam moved ground floor on fault
- 🤝 **60s Peer Buddy Assist** - +2 AICTE Activity Points credited
- 🏫 **Classroom Companion** - Board OCR & Live Speech Captions

### Technology Stack
- 🗺️ **3D Campus Digital Twin** - Interactive spatial navigation
- 📹 **YOLOv11-Nano Edge Vision** - Real-time obstacle detection
- 🤖 **Autonomous n8n Workflow** - Self-healing rerouting
- 🛗 **MQTT Smart Elevator** - Pre-summoned with door hold
- 📱 **Mobile PWA Interface** - Student companion app
